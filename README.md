## Projeto em destaque

### [Simulação de busca com drones](https://github.com/RafaTavares21/Projeto-busca-com-drones)

Simulação interativa de reconhecimento de uma área e entrega de suprimentos, desenvolvida com **HTML, CSS e JavaScript**, com visualização em **Canvas**.

- Busca em largura (**BFS**) para explorar uma grade de 40 × 40 células.
- Algoritmo de **Dijkstra** para calcular caminhos durante as entregas.
- Animação do percurso, identificação de pessoas e retorno à base.
- Controles para iniciar o reconhecimento, realizar entregas e reiniciar a simulação.
